# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: on this repository's
**Security** tab, choose **Report a vulnerability**. Include what's affected, how to reproduce it and
what an attacker could do with it.

We'll reply within a few working days, keep you posted while we fix it, and credit you in the
advisory unless you'd rather not be named.

## Supported versions

Fixes go into the latest release of each package, `@rocksoliddigital/storybook-addon-lineage` and
`@rocksoliddigital/payload-lineage`. Upgrade to it to get them.
